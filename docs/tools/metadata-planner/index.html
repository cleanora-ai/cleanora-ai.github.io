What this preview means

Extension groups are a manual planning aid. A PDF with an invoice name may still contain something else; this tool does not inspect the document. Missing or invalid dates stay in Review. Cleanora's real Modified date mode reads file metadata locally after you select a folder, while this page only uses dates you type. Neither this page nor Cleanora deletes files or detects duplicates.

For a small folder, File Explorer sorting and manual moves may be enough. Cleanora is useful when you need a reviewed physical move plan for a larger Windows 10/11 folder. It classifies supported files from filenames, extensions, dates, and metadata, then shows exact destinations and conflicts before approval. Scan and preview are available without a license; applying or undoing moves requires activation. Download and licensing need internet access, while file planning stays local.
