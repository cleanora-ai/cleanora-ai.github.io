Supported files and limits

Cleanora can sort PDF, DOCX, TXT, XLSX, CSV, PPT, PPTX, PNG, JPG, WEBP, ZIP, 7Z, RAR, EXE, and MSI files using filenames, extensions, dates, and metadata. It does not read document contents or use a cloud model to classify them. You can exclude items before applying a plan. A valid license is required to apply or undo moves. Undo uses an authenticated local audit, applies only to a successful operation that has not already been undone, and refuses the whole restore if an original path is occupied.

How Cleanora works

  1. Select a folder on your computer.
  2. Cleanora classifies filenames, extensions, dates, and metadata locally.
  3. Review proposed categories, destinations, and conflicts.
  4. Apply only the changes you approve.
